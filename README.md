# Overleaf Template for Research Proposal Report at Southeast University

An unofficial LaTeX template for the Research Proposal Report and Dissertation Implementation Plan at Southeast University.

This template is compiled with XeLaTeX.

Original version in DOCX format: [SEU Graduate School](http://seugs.seu.edu.cn/3676/list.htm)

This version is intended for professional doctoral students. A version for academic doctoral students may be added later if the official requirements differ.

You are welcome to modify the template as needed.

## Usage

1. Create a blank project on Overleaf.
2. Upload `main.tex` and `ref.bib`.
3. Select `XeLaTeX` as the compiler in the project settings.
4. Recompile the project.
